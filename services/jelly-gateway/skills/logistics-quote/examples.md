# logistics-quote1.5 使用示例

# 使用示例

## 干净测试

```bat
reset_sessions.bat
```

或使用内部调试命令：

```bat
run_quote.bat "/重置任务"
```

## 成本查询阶段

```bat
run_quote.bat "LAX9，300kg，深圳仓，包税，有什么方案？"
```

预期行为：

- 创建任务编号。
- 查询远程数据库报价服务；本版本不包含本地 Excel 报价文件，也没有本地 Excel 回退。
- 单仓询价以竖向卡片展示全部匹配成本方案。
- 每张卡片按固定顺序显示：来源报价表、工作簿、渠道、运输方式、起运仓、税务类型、计费方式、成本单价、重量/体积/件数、参考时效、船期。

## v1.5 区域化渠道显示

- 当前后端参考为 `docs/4.md`。
- 美国线路：`渠道` 优先显示产品/渠道名 + 仓库代码，例如 `美东整柜直送MDDZG｜ABE8`。
- 欧洲/英国线路：`渠道` 优先显示 `下单渠道 + 服务国家`；如果后端返回等价字段，则使用 `子渠道 + 国家或分区`。
- 欧洲仓库代码可能出现在 `服务国家` / `国家或分区` 内，例如 `德国-DTM2`，匹配时必须检查这些字段。
- 如果欧洲线路的最终 `渠道` 没有包含请求的仓库代码，会追加仓库代码以便操作同事定位，例如 `倔强青铜-欧铁经济BS 德国 DTM2`。
- 不使用 `欧洲/英国成本表 · 海运` 这类泛化摘要作为最终 `渠道`。
- `卡派` 是派送方式，不是 `卡航`；`海卡` 表示 `海运 + 卡派`。
- 批量多仓输出中，如果性价比最高和时效最快不是同一个方案，必须分别展示。

## 欧洲/德国多仓同条件询价

输入：

```text
深圳
欧洲、德国
MHG9 、DTM2、DTM1、BER8、RLG1，海运，包税，100KG以上
卡派
```

预期：

- 识别全部仓库：`MHG9`、`DTM2`、`DTM1`、`BER8`、`RLG1`。
- 起运仓识别为 `深圳`，并作为显式起运地发送给远程数据库。
- `海运` 是运输方式；`卡派` 是派送方式，不等同于 `卡航`。
- `包税` 会过滤掉 `自税`、`不包税`、`递延` 等不兼容方案。
- `100KG以上` 在输出中保留为 `重量：100KG以上`。
- 每个方案卡片都完整显示固定字段顺序；缺失字段显示 `未返回`。
- 后端字段 `工作表` 在 Skill 输出中显示为 `工作簿`。
- 如果参考时效或船期未返回，显示 `参考时效：未返回` / `船期：未返回`，不编造。
- 空字段显示 `未填写`。
- 全部匹配方案保存到 `quote_sessions.json`。
- 状态变为 `等待输入毛利率`。

## 批量多仓询价

```bat
run_quote.bat "/中断并新开 发慢船，麻烦报下价\nRDU2-----190KG\nFTW1-----141KG\nSMF3-----123KG\nAVP1-----177KG\nMDW2-----304KG"
```

预期行为：

- 创建一个批量报价任务。
- 识别 5 个 `batch_items`：RDU2/190KG、FTW1/141KG、SMF3/123KG、AVP1/177KG、MDW2/304KG。
- 因 5 个仓库重量不同，远程调用时按仓库分别查询，每个请求使用该仓库自己的实际重量。
- 如果批量任务中所有仓库重量完全相同，则可合并仓库代码到 `仓库/航线`，并使用接口返回的 `按FBA仓报价` 分仓展示。
- 每个仓库只展示 `性价比最高` 和可比较 ETA 下的 `时效最快` 方案。
- 保留数据库返回的具体渠道名称，不合并成泛化的海运/空运方案。
- `发慢船` 不会自动强制筛选为海运。
- 如果接口未返回参考时效，显示 `参考时效：未返回`，且不标注 `时效最快`。

批量统一毛利率：

```bat
run_quote.bat "统一按15%"
```

预期行为：

- 对每个仓库当前展示的代表方案统一应用 15% 毛利率。
- 最终报价和客户可发送文本都按仓库分组。

## 明确筛选与口语描述

```bat
run_quote.bat "/中断并新开 LAX9，300kg，只看空运"
```

预期：只保留空运相关方案。

```bat
run_quote.bat "/中断并新开 发慢船，RDU2 190KG"
```

预期：不因为 `慢船` 二字自动丢弃其他有效方案，除非客户明确说 `只看海运` 或 `只走慢船`。

## 统一毛利率

```bat
run_quote.bat "统一按15%"
```

预期行为：

- 对已保存成本方案统一应用 15% 毛利率。
- 最终报价内部最多展示 10 个方案。
- 最终报价卡片沿用相同字段顺序，并额外显示报价单价和预估总价。
- 报价单价和预估总价保留 2 位小数。
- 客户可发送报价最多展示 5 个方案。

## 未匹配示例

```bat
run_quote.bat "/中断并新开 英国5方，深圳仓，包税"
```

预期：缺少目的仓信息，输出 `【请客服补充】`。

```bat
run_quote.bat "/中断并新开 XYZ999，300kg，深圳仓，包税"
```

预期：成本表无该线路数据，输出编号式 `【建议处理】`。

```bat
run_quote.bat "/中断并新开 LAX9，300kg，深圳仓，包税，空运"
```

预期：筛选条件过严，输出 `【可能过严的条件】` 和 `【建议处理】`。

```bat
run_quote.bat "/结束任务"

```
