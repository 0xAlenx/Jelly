## 询价字段约定（MCP 与 REST 一致）

| 含义 | MCP `quote_freight` 参数 | REST JSON 键（示例） |
|------|-------------------------|----------------------|
| 目的地 | `destination` | `目的地` |
| 实重 kg | `weight_kg` | `重量` |
| 方数 CBM | `cbm` | `方数` |
| 起运地 | `origin` | `起运地` |
| 仓库/航线 | `warehouse_route` | `仓库/航线` |
| 件数 | `pieces` | `件数` |
| 偏远/私人/保险 | `remote_area` 等 | `是否偏远地区` 等 |

- 美国：目的地字符串里尽量带 **5 位邮编** 以便分区。  
- 欧洲深圳仓：起运地或描述里含「深圳」且只走深圳仓价时写 `深圳`。  
- 计费重：`max(实重, 方数×1e6/6000)`。
- **多仓一次写**：`仓库/航线` 里可写多个 FBA 代码（如 `RDU2 FTW1 SMF3`）。返回 JSON 会多出 **`按FBA仓报价`** 数组，每仓单独解析邮编与方案；顶层 `方案列表` 仍为合并排序（美国空派邮编仍对应「首仓」逻辑，分仓请以 `按FBA仓报价` 为准）。
- **海运同义词**：`慢船`、`慢线`、`普船`、`海卡`、`船运`、`散货`、`以星`、`美森` 等会推断为 **海运**（与填 `海运` 等效）。
- **参考时效**：依赖库里 `cost_rate_rows.reference_eta` / `rate_lines.transit_text`；**远端简化库若未同步该列，接口会返回空时效**，需在报价机同步完整成本表或看返回里的提示说明。
