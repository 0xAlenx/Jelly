模型网关说明

普通用户不能自己配置模型，所有请求经过 JellyAI。

  1. 用户发起请求本地 JellyAI 客户端发送 skill、消息和授权 token。
  2. 网关鉴权检查密钥、到期时间、套餐权限和剩余积分。
  3. 扣除积分根据模型成本倍率和 skill 类型计算消耗。
  4. 调用模型使用 JellyAI 统一模型池，不暴露模型密钥给用户。
  5. 记录日志保存调用记录、成本、用户和 skill 数据。
